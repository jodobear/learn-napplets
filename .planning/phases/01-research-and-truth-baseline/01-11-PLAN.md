## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted iframe guest → local harness | Guest code attempts browser messaging and domain access. |
| browser behavior → protocol/host conclusion | Browser observations need source/policy separation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-11-01 | Elevation of Privilege | iframe fixture | high | mitigate | Use sandboxed clean contexts, fake services, no secrets, and explicit domain removal cases. |
| T-11-02 | Spoofing | message/source mapping | high | mitigate | Measure actual `MessageEvent.source` mapping and report it as observation with replay data. |
| T-11-03 | Information Disclosure | browser egress/state | high | mitigate | Isolate fixture, avoid real credentials/state, and retain only bounded evidence output. |
| T-11-04 | Tampering | browser conclusion | medium | mitigate | Separate upstream source claims, browser observation, and proposed policy in the report. |
| T-11-SC | Tampering | Playwright/browser runtime | high | mitigate | Reuse Plan 01’s approved browser toolchain and record executable/version/flags. |
</threat_model>
