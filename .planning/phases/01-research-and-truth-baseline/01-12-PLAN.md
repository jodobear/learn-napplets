## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest/artifact fixture → verification observation | Fixture identity and bytes determine whether a conclusion is reproducible. |
| verification observation → teaching-host recommendation | An implementation-specific result must not become protocol authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Tampering | artifact/manifest bytes | high | mitigate | Pin exact-byte digest, source baseline, and mutation fixture before verification. |
| T-12-02 | Spoofing | verification conclusion | high | mitigate | Cite public/reviewed verification evidence and label observations versus source requirements. |
| T-12-03 | Elevation of Privilege | cryptographic experiment | high | mitigate | Do not hand-roll verification or use production credentials; record blocked result where evidence is unavailable. |
| T-12-04 | Repudiation | identity recommendation | medium | mitigate | Preserve commands, tool versions, errors, digests, uncertainty, and ADR impacts. |
| T-12-SC | Tampering | verification dependencies | high | mitigate | Reuse human-approved tools only; any additional package requires a new blocking review. |
</threat_model>
