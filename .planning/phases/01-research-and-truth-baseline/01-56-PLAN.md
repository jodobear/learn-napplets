<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| final external review → detached execution | A verifier could test a different commit or use a review record that does not bind the test inputs. |
| candidate/reviewer/verifier identities → independent result | Identity reuse could allow self-certification. |
| command output → independent report | A partial, duplicate, stale, or altered result batch could be represented as complete verification. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-56-01 | Tampering | tested commit | high | mitigate | Task 1 requires reviewed and tested commit equality and executes only in the detached worktree at that commit. |
| T-56-02 | Spoofing | independent verifier | high | mitigate | Task 1 requires pairwise distinct candidate executor, final reviewer, runtime executor, and verifier identities. |
| T-56-03 | Tampering | independent batch | high | mitigate | Task 1 validates every required command, result digest, count, uniqueness, and binding before report publication. |
| T-56-04 | Elevation of Privilege | independent report | high | mitigate | Task 1 preserves blocked evidence and no-authorization boundaries, and leaves State/Roadmap untouched. |
</threat_model>
