## Trust Boundaries

| Boundary | Description |
|---|---|
| reviewed Git tree metadata → raw HTTPS bytes | A commit/path endpoint can return bytes that do not match the reviewed blob object. |
| collected outcomes → registered four-file canonical generation | A different publisher/reader root or sequential writes can expose a mixed immutable-evidence generation. |
| concurrent/rerun collector → existing immutable history | A second writer can collide, overwrite, duplicate, or delete a prior generation. |
| caller output arguments → canonical repository files | A merely confined regular path can redirect publication over unrelated project state. |
| canonical queue/receipt → production validator | Sequential pathname reads can combine two valid same-binding documents from different publication generations. |
