## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public HTTPS response → collected bytes | Repository identity, refs, paths, and bytes are untrusted until pinned and hashed. |
| observed merge/release material → source classification | Implementation and release observations must not become normative protocol or package evidence. |
| acquisition history → later authority decision | A new attempt must not erase prior discovery, failure, or blocked scope. |
