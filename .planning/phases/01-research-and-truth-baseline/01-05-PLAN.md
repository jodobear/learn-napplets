<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public upstream/network → collector | Network responses, repository refs, paths, and source text are untrusted until pinned. |
| cache → committed canonical records | Cache contents are not themselves evidence and must remain ignored. |
| source records → claims/maps | Collection metadata must not turn directional evidence into verified fact. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | mutable refs and source bytes | high | mitigate | Resolve commit and blob before digesting; store immutable identity and record changes/failures. |
| T-05-02 | Spoofing | upstream host identity | high | mitigate | Restrict acquisition to official/authorized repositories and retain authority/authenticity fields. |
| T-05-03 | Repudiation | acquisition failures | medium | mitigate | Append dated retry/failure and affected-work records instead of reporting a clean refresh. |
| T-05-04 | Information Disclosure | source cache | medium | mitigate | Keep clones/downloads outside version control and commit only minimal license-aware excerpts/digests. |
| T-05-SC | Tampering | collector runtime | high | mitigate | Use the reviewed toolchain and no authenticated or write-capable network operations. |
</threat_model>
