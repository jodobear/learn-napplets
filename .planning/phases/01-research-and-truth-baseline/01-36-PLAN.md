## Trust Boundaries
| Boundary | Description |
|---|---|
| compatibility/approval records → package runner | Incomplete evidence could otherwise invoke a package operation. |
| package root export → isolated fixture | A package can execute scripts or a fixture can import private paths. |
| measurement result → compatibility/ADR evidence | An import result could be overstated as conformance or protocol fact. |
