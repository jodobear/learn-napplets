## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| package registry → isolated SPK-B environment | Candidate framework code is untrusted until human-reviewed. |
| disposable framework output → repository | Experiment files must not become a Phase 1 production scaffold. |
| framework metrics → ADR 0002 | Measurements must be reproducible and recommendation-only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-10-01 | Tampering | framework packages | high | mitigate | Blocking human review approves exact package versions/provenance before isolated installation. |
| T-10-02 | Elevation of Privilege | framework spike outputs | high | mitigate | Constrain fixtures/dependencies to SPK-B and validate the no-production marker gate. |
| T-10-03 | Repudiation | recommendation evidence | medium | mitigate | Record commands, environment, digests, measurements, uncertainty, and proposed/blocked status. |
| T-10-SC | Tampering | package installs | high | mitigate | Human checkpoint cannot be auto-approved and records per-candidate decision before install. |
</threat_model>
