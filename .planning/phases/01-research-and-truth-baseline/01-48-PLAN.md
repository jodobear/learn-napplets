<threat_model>
## Trust Boundaries
| Boundary | Failure | Mitigation |
|---|---|---|
| canonical evidence → public copy | Uncertain implementation detail presented as protocol fact | Structured status/source IDs rendered beside claims |
| structured content → generated HTML | Injection or unsafe output path | Strict schema/reference checks, escaping, fixed route map, atomic writes |
| optional JavaScript → essential learning | Content inaccessible when scripts fail | Serverless static HTML contains all essential meaning |
| public page → external systems | Site silently depends on live service/package/runtime | Local-only assets and browser network assertion |
</threat_model>
